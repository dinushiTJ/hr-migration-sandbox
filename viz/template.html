__DOCS__

What this is. A replay of one deterministic run over synthetic data. The counts, the money and every rejection come from the pipeline's own SQLite output, exported after the run, so nothing here is re-narrated by hand. What it is not. the target is Workday-shaped and has never been loaded into a Workday tenant, there is no EIB or iLoad file format, no incremental or delta load, and the cleansing rules were asserted in code rather than agreed with data owners.
