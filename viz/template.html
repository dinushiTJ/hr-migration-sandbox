Notes

What this is. A replay of one deterministic run over synthetic data. The counts, the money and every rejection come from the pipeline's own SQLite output, exported after the run, so nothing here is re-narrated by hand.

What it is not. The target is Workday-shaped and has never been loaded into a Workday tenant. There is no EIB or iLoad file format, no incremental or delta load, and the cleansing rules were asserted in code rather than agreed with data owners.

How it works, the validity checks and the known issues are in the documentation. A plain-English version is in the FAQ.
