# Capability note: the current Microsoft 365 fundamentals certification

Notes from working out which Microsoft 365 fundamentals certification is actually current,
and what free training sits behind it. Checked September 2026.

## MS-900 is retired

MS-900, Microsoft 365 Fundamentals, is the certification most guides and job descriptions
still name. It is retired. Its
[certification page](https://learn.microsoft.com/en-us/credentials/certifications/microsoft-365-fundamentals/)
now carries the notice "This certification is retired", pointing at Microsoft's
[certifications refresh announcement](https://techcommunity.microsoft.com/blog/skills-hub-blog/certifications-refresh-ai-focused-and-fundamentals-updates/4446638),
and its "Prepare for the exam" section reads "No training available for this exam". The
exam can no longer be scheduled.

So there is no current free learning path for MS-900. Anything presented as one is either
stale or is describing different content.

## AB-900 is the current fundamentals certification in this space

[Microsoft 365 Certified: Copilot and Agent Administration Fundamentals](https://learn.microsoft.com/en-us/credentials/certifications/copilot-and-agent-administration-fundamentals/),
exam code AB-900. Beginner level, 45 minutes, proctored, currently offered in English,
scheduled through Pearson Vue or through Certiport for students and educators.

The three areas assessed:

- Identify the core features and objects of Microsoft 365 services
- Understand data protection and governance tasks for Microsoft 365 and Copilot
- Perform basic administrative tasks for Copilot and agents

**It is not a renamed MS-900.** This is worth being precise about, because plenty of
secondary sources describe it as a straight rename. Microsoft's own guidance is that
AB-900 is a separate fundamentals certification focused on Copilot and agents, rather than
MS-900's broad tour of Microsoft 365. Its candidate profile assumes familiarity with the
admin centres behind Exchange Online, SharePoint, Teams, Microsoft Entra and Microsoft
Purview, and experience with AI-driven productivity tools. MS-900 assumed none of that.

For anyone whose interest is Microsoft 365 *and* AI-enabled tooling together, that shift
makes AB-900 the more relevant target rather than a lesser substitute. For anyone who
wanted MS-900's general Microsoft 365 overview and nothing else, it is a narrower exam
with a higher floor.

## The free self-paced training

Two learning paths on Microsoft Learn, free, self-paced, beginner level, three modules
each. Between them their six modules map onto the exam's three assessed areas:

- [Explore Microsoft 365 administration](https://learn.microsoft.com/en-us/training/paths/explore-microsoft-365-administration/):
  security foundations, core services and admin controls, then data protection and
  governance.
- [Explore Microsoft 365 Copilot and agent administration](https://learn.microsoft.com/en-us/training/paths/explore-microsoft-365-copilot-agent-administration/):
  Copilot and agents, administering Copilot, then administering agents.

Both paths state prerequisites: basic functional experience with Microsoft 365 services,
and a proficient understanding of general IT practices. They are not a cold start.

Do not confuse these with
[Course AB-900T00-A, "Introduction to Microsoft 365 and AI administration"](https://learn.microsoft.com/en-us/training/courses/ab-900t00).
That shares much of the content but is a one-day course listed at 24 hours to complete and
is delivered instructor-led or as self-directed study, not a free learning path. The
similar name makes this an easy thing to cite by mistake.

Also free and worth using before booking anything: the
[AB-900 study guide](https://aka.ms/ab900-StudyGuide), and the practice assessment and
exam sandbox linked from the certification page.
